Markdown 排版速查

這篇文章同時也是一份 Markdown 語法示範。你現在讀到的每一種格式，原始都是純文字寫成。

標題層級

用 # 到 ###### 表示 h1–h6。上面這行是 h2。

強調與連結

可以 加粗、斜體、刪除線，也能放超連結。

清單

無序清單：

  • 蘋果
  • 香蕉
    • 子項目也可以縮排
  • 橘子

有序清單：

  1. 打開編輯器
  2. 寫一篇 .md
  3. 執行 node build.js

引用

寫作是為了把模糊的想法，逼成清楚的句子。

程式碼

行內程式碼像這樣 const x = 1，區塊程式碼像這樣：

function hello(name) {
  return `你好，${name}`;
}
console.log(hello('世界'));

# 標題 章節
- 項目 清單
