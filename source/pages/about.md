# 關於這個部落格

這是我用來自由寫作的獨立空間。

它完全獨立於我其他的網站與工作專案，有自己的程式碼庫與部署方式。你可以把它想成我的「數位自留地」。

## 技術

- 文章以 Markdown 撰寫，存放於 `source/posts/`
- 用 Node 腳本 `build.js` 編譯成純靜態 HTML
- 可部署到任何靜態主機（Netlify、GitHub Pages、Vercel、自己的空間……）
